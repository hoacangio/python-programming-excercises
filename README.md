# Python Programming Exercises & Stock Tracking Project

Workspace này gồm các bài tập Python cơ bản và một ứng dụng theo dõi chứng khoán.

## Cấu trúc thư mục

- [bai-tap-3/](bai-tap-3/README.md) — các bài tập Python cơ bản (đếm ký tự, kiểm tra email, kéo búa bao,...)
- [theo-doi-chung-khoan/](theo-doi-chung-khoan/README.md) — ứng dụng theo dõi danh mục chứng khoán bằng Python + Streamlit (hướng dẫn cài đặt/chạy bằng Docker và không Docker nằm trong README của thư mục này)

## Yêu cầu chung

- Python 3.10+
- Git
- Docker và Docker Compose (chỉ cần nếu chạy `theo-doi-chung-khoan` bằng Docker)

Kiểm tra phiên bản Python:

```bash
python --version
```

## Clone project

```bash
git clone <url-repository>
cd python-programming-excercises
```

## Chạy các bài tập trong `bai-tap-3`

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
python bai-tap-3/bai_1_dem_ky_tu.py
```
