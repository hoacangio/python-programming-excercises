# Danh mục từ viết tắt và thuật ngữ

| Từ viết tắt / thuật ngữ | Ý nghĩa |
| --- | --- |
| BUY / SELL | Lệnh mua / lệnh bán |
| CSDL | Cơ sở dữ liệu |
| FR / NFR | Yêu cầu chức năng (Functional Requirement) / phi chức năng (Non-Functional Requirement) |
| HOSE, HNX, UPCoM | Sở Giao dịch Chứng khoán TP.HCM, Hà Nội và thị trường đăng ký giao dịch |
| OHLCV | Giá mở cửa, cao nhất, thấp nhất, đóng cửa và khối lượng (Open, High, Low, Close, Volume) |
| PnL | Lãi/lỗ (Profit and Loss) |
| Repository | Lớp trung gian duy nhất đọc/ghi CSDL |
| Tiến trình nền (worker) | Chương trình chạy độc lập với giao diện, định kỳ kiểm tra cảnh báo |
| Dashboard | Trang tổng quan danh mục |
| VND | Đồng Việt Nam; mọi giá trong báo cáo tính theo đồng |
