## 🏗️ SLIDE 4: KIẾN TRÚC CÔNG NGHỆ (90 giây)

### 🎯 Hành Động
- Click vào SLIDE 4
- Chỉ từng tầng (Presentation → Services → Data)

### 🎤 LỜI THOẠI

#### Mở đầu (10 giây)
```
"Phía dưới giao diện, chúng tôi xây dựng 1 kiến trúc rất thông minh
gọi là **MSU** - một phiên bản mini của MVC.

Gồm 3 tầng chính:
```

#### Tầng 1: Presentation (15 giây)
```
🖥️ TẦNG 1: GIAO DIỆN (Presentation Layer)

Được xây dựng bằng STREAMLIT:
   • Web framework Python hiện đại
   • Làm được giao diện chuyên nghiệp từ code Python
   • Không cần HTML/CSS/JavaScript

Tầng này chứa 3 trang chính:
   ✓ Dashboard Page (xem danh mục + biểu đồ)
   ✓ Add Transaction Page (nhập giao dịch)
   ✓ Alert Settings Page (cài đặt cảnh báo)
```

#### Tầng 2: Services (25 giây)
```
⚙️ TẦNG 2: DỊCH VỤ (Services Layer)

Đây là "bộ não" của ứng dụng, viết bằng Python thuần:
   
   📊 portfolio_service.py
      → Tính danh mục, giá vốn trung bình, PnL
   
   💹 market_data_service.py
      → Kéo dữ liệu giá real-time từ yfinance
   
   📈 chart_service.py
      → Vẽ biểu đồ Candlestick interactive
   
   🔔 alert_service.py
      → Quản lý Stop-Loss, Take-Profit
   
   📱 messaging_service.py
      → Gửi tin nhắn qua Telegram Bot API

💡 ĐẶC BIỆT:
   ✓ Tầng này **KHÔNG import Streamlit**
   ✓ Có thể dùng chung cho web app và alert bot (background worker)
   ✓ Dễ viết test, dễ bảo trì
```

#### Tầng 3: Data (20 giây)
```
💾 TẦNG 3: DỮ LIỆU (Data Layer)

Repositories: Lớp trung gian truy cập database
   📁 user_repository.py
   📁 transaction_repository.py
   📁 alert_repository.py
   📁 market_repository.py

Database: SQLite (chạy local, 0 chi phí)
   🗂️ users: Lưu username, telegram_chat_id
   🗂️ transactions: Lưu BUY/SELL history
   🗂️ price_alerts: Lưu Stop-Loss/Take-Profit config
   🗂️ market_prices: Cache dữ liệu giá
```

#### Docker (20 giây)
```
🐳 DEVOPS: DOCKER & DOCKER COMPOSE

Chúng tôi dùng Docker để phát triển:

docker-compose.yml chứa 2 services:
   
   🔷 app service
      → Streamlit web app
      → Chạy tại http://localhost:8501
   
   🔶 alert_bot service
      → Python script chạy 24/7
      → Kiểm tra giá mỗi 5 phút
      → Gửi Telegram alert

✨ LỢI ÍCH:
   ✓ 1 lệnh: `docker compose up` → Chạy toàn hệ thống
   ✓ Độc lập môi trường (dev, test, prod)
   ✓ Dễ scale, deploy, rollback
   ✓ Database tồn tại khi dừng container
```

### 💡 GỢI Ý NÓI
- Nói từng tầng **từ dưới lên** (hoặc từ trên xuống, nhưng NHẤT QUÁN)
- Khi nói "KHÔNG import Streamlit", làm giọng nhấn mạnh - đây là điểm kỹ thuật quan trọng
- Giơ 3 ngón tay lúc đầu, chỉ từng tầng
- Tại Docker, nói chậm `docker compose up` - dễ nhớ
- Nhấn mạnh "1 lệnh" - đó là sự thuận tiện

## 📝 TIPS THUYẾT TRÌNH

### 🎙️ Về Tạo Sự Tập Trung
- **Mở đầu mạnh**: "Chào các bạn, hôm nay tôi sẽ nói về 1 vấn đề mà mình gặp..."
- **Dùng hình ảnh**: Mỗi slide đều có emoji + màu sắc
- **Nói chậm ở con số**: Pause 1 giây sau "95%", "15-20%", "0 VND"
- **Thay đổi intonation**: Đừng nói một mực, thay đổi giọng giữa các idea

### 👁️ Về Liên Lạc Mắt
- Nhìn vào khán giả, không chỉ nhìn slide
- Scan từ trái sang phải
- Nên nhìn vào mắt người phát biểu/hỏi (nếu có)

### 🎯 Về Cử Chỉ
- Giơ tay khi nói "3 vấn đề", "3 chức năng", "3 tầng"
- Chỉ tay vào slide khi nói chi tiết
- Tránh bàn tay sau lưng hoặc bỏ tay vào túi

### ⏱️ Về Thời Gian
- Đồng hồ ở tay: Kiểm tra từng 30 giây
- Nếu chậm: Bỏ đi vài ví dụ, tập trung vào idea chính
- Nếu nhanh: Thêm 1-2 ví dụ thực tế

### 🆘 Nếu Quên Lời
- **Dừng, sâu thở**: "Cho tôi một giây..."
- **Nhìn slide**: "À đúng, tiếp theo là..."
- **Tiếp tục**: Không cần nói "Tôi quên, xin lỗi"
